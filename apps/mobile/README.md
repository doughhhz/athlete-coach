# Mobile application (placeholder)

Destino da futura aplicação React Native + Expo + TypeScript.

- `app/`: rotas e layouts do Expo Router; somente composição e navegação.
- `src/presentation/`: componentes, hooks e estado local de apresentação.
- regras de negócio devem vir de `packages/application` e `packages/domain`.

Nenhum projeto Expo foi gerado na Phase 0 para evitar dependências e código prematuros.
